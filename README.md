# Jogo de Adivinhação em Python

Projeto desenvolvido em Python para praticar lógica de programação, loops, condicionais e manipulação de strings.

O jogo funciona para dois jogadores:
- Um jogador escolhe a palavra secreta
- O outro tenta descobrir letra por letra

## 🎮 Funcionalidades

- Sistema de adivinhação de palavras
- Exibição da palavra parcialmente descoberta
- Contador de tentativas
- Sistema de erros
- Condição de vitória e derrota
- Reinício automático do jogo
- Compatibilidade com Windows e Linux

## 🧠 Conceitos praticados

- `while`
- `if / else`
- `for`
- Funções nativas
- Manipulação de strings
- Loops
- Tratamento de lógica
- Limpeza de terminal com `os.system()`

## 🚀 Tecnologias

- Python 3

## ▶️ Como executar

```bash

```

```bash
cd nome-do-repositorio
```
